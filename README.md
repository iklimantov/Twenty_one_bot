# 🃏 Telegram Bot: Игра в 21 (Очко)

## Обзор проекта 🚀

Это Telegram бот, позволяющий пользователям сыграть в популярную карточную игру **"21"** (также известную как **"Очко"** или **Blackjack**) прямо в чате. Бот выступает в роли дилера, ведёт игру, подсчитывает очки и статистику побед.

Проект реализован на **Python** с использованием библиотеки `aiogram` для работы с Telegram Bot API.

---

## ✨ Основные возможности

* **Классический геймплей:** Полная реализация правил игры "21" против дилера.
* **Управление игрой:** Команды для начала игры (`/game`), завершения (`/quit`), просмотра правил (`/rules`) и помощи (`/help`).
* **Интерактивный ход:** Пользователь может набирать карты, используя ключевые слова, такие как "еще", "хватит" и т.п.
* **Подсчет статистики:** Отслеживание общего количества игр, побед и процента выигрышей с помощью команды `/stat`.
* **Обработка тузов:** Корректный подсчет очков, когда Туз может быть 1 или 11.
* **Корректная обработка нескольких одновременных игровых сессий**

---

## 🛠️ Технологии

* **Язык:** Python (3.12)
* **Фреймворк:** `aiogram` (v3)
* **Конфигурация:** `environs` (для безопасного хранения токена)

## ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/iklimantov/Twenty_one_bot
cd Twenty_one_bot
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows
```

### 3. Установка зависимостей
Все необходимые библиотеки указаны в файле requirements.txt:

```bash
pip install -r requirements.txt
```

### 4. Настройка токена бота 🔑
Создайте файл .env в корне проекта на основе шаблона .env.example и вставьте ваш Telegram Bot Token.

```
BOT_TOKEN='ВАШ_ТОКЕН_БОТА'
```
Токен можно получить при создании своего бота в @BotFather

### 5. Запуск бота ▶️

```bash
python main.py
```

## 🎮 Команды бота
```
/start	Приветствие и инициализация пользователя.
/help	Показать список доступных команд.
/game	Начать новую игру в "21".
/quit	Закончить текущую игру.
/rules	Посмотреть основные правила игры.
/stat	Посмотреть личную статистику игр.
"еще"	Взять ещё одну карту (во время игры).
"хватит"	Остановиться и перейти к ходу дилера (во время игры)
```
